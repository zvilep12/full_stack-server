# full_stack-server
עבודת גמר קורס full stack server
שרת זה הוא שרת restful api לניהול מסעדה, שישומש על ידי עובדי המסעדה ומכיל מעט פונקציות גם ללקוחות.
על מנת שעובד יוכל להשתמש בשרת הוא צריך לפני זה לעבור אימות דו שלבי עם קוד שנשלח למייל שתקף ל5 דקות. ברגע ההתחברות העובד יקבל טוקן של 8 שעות (משמרת) ולאחר מכן ידרש לבצע הץתחברות מחדש.
על מנת להפעיל את השרת יש למלאות את הפרטים הדרושים בקובץ env.

#/auth
/login POST
התחברות, צריך להכניס שם מלא \ תעודת זהות \ כתובת דואר אלקטרוני וסיסמה
/verify POST
אימות דו שלבי, צריך לשים את הקוד שנשלח במייל ואת הטוקן הזמני שהתקבל ב/logn


#/customer 
/ POST
יצירת משתמש, רק לעובדים עם role ניהולי
/ GET
מקבל רשימה מלאה של כל העובדיפ
/name/:name GET
חיפוש עובד על פי שם
/:id GET
חיפוש עובד על פי תעודת זהות
/:id PUT
עדכון פרטי עובד על פי תעודת זהות
/:id DELETE
מחיקת עובד על פי תעודת זהות
